# Archive

This directory stores historical or one-off project artifacts that are not part
of the active release path.

- `legacy-sql/` contains older bootstrap, reset, or broad remediation SQL.
- `ad-hoc-scripts/` contains manual inspection or temporary test scripts.

These files are kept for reference only. Active work should use the focused SQL,
current docs, and live code paths that remain in the repo root and `supabase/`.
